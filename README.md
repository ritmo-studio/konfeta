# konfeta.group

Сайт «Конфеты» на `ritmo-engine`: страница — PHP с инклюдами, базы нет,
контент в `content/`. Вёрстка перенесена с согласованной
`dev.konfeta.group` (WordPress) и переразмечена по правилам
SEO Design System.

- Снимок библиотеки: **SEO Design System v.0.78**, Figma `6avxpE8zkv7lLs2G2f4Oah`
- Движок: **ritmo-engine 0.12**, копией в `engine/` (обновлять `engine/tools/sync-engine.py`)
- Дата отреза: 2026-11-03

Связи с библиотекой нет: правки сайта в неё не едут, её обновления сюда
не приходят. Блок, родившийся здесь и понадобившийся второй раз,
переносится в библиотеку руками и только через Figma.

## Префиксы

| Префикс | Что это | Можно ли менять |
|---|---|---|
| `rs-` | блоки движка: `main`, `preloader`, `page-404` | только сайтовые значения |
| `sds-` | приехало из библиотеки без изменений | нет: имя обещает соответствие, и на этом держится `diff` |
| `kf-` | собственные блоки «Конфеты» | свободно |

Подогнал библиотечный блок под сайт — переименуй в `kf-`.

## Токены

`tokens.css` — снимок библиотечного файла плюс две добавки:

1. набор объявлен и на `:root`: блоки `kf-` корня `.sds` не имеют, а темы
   WordPress, от которой библиотека отгораживалась, здесь нет;
2. мост `--rs-*` → `--sds-*` для блоков движка. Движку нужно 22 переменные
   `rs-` (в `engine.json` перечислены три — список там неполный), значения
   им даёт библиотека, чтобы источник правды остался один.

## Состав главной

Инвентаризация `dev.konfeta.group` от 2026-11-03. Из 12 секций близкие
аналоги в библиотеке были у 4–5, и каждый потребовал бы подгонки, —
поэтому контентные блоки делаются собственными: так результат совпадает
с утверждённой вёрсткой, а имена `sds-` не превращаются в форки.

## Что сделано иначе, чем на старом сайте

- **`h1` появился.** На `dev.konfeta.group` его не было ни одного (`h2` два,
  `h3` пять). Достаётся блоку 2.
- **`cta-sticky` добавлен.** В блоках старой главной нет ни одной настоящей
  кнопки: заявка шла только через модалку из мобильного меню.
- **Swiper выброшен.** Слайдеры садятся на `atoms/slider` библиотеки —
  там уже вылечен захват указателя, съедавший клики внутри карточек.
- **Bootstrap-модалки выброшены.** 5 форм в 7 окнах `.modal.fade` — времянка
  с WordPress. Карточки блока 7 на первой итерации статичны (`div`, не
  `a href="#"`), чтобы потом не выковыривать мёртвые `data-toggle`.
- **Cookie-баннер** (`.popup-cookies`) пока не переносится.
- **Анимация движковая:** `rs-anim` и наблюдатель `engine/base.js`.
  `base.js` и `base.css` библиотеки сюда не едут — иначе два наблюдателя
  на одних элементах. Поведение анимаций пересобирается заново, а не
  переносится.

## Отложено отдельными итерациями

1. **Картинки.** 43 фото и 36 логотипов. На старом сайте лежат уже
   нарезанные под слот (`img-1-1740px.jpg`), апскейлить нельзя — нужны
   мастера из Figma «Конфеты» или от клиента, дальше `make-images.py`.
2. **Формы и приёмник POST.** В движке обработчика нет: нужны приём,
   антиспам, уведомление. Разрабатывается в движке, подключается сюда.
3. **Hover, состояния модалок, пустой результат фильтра** — по Figma,
   в DOM их не видно.
4. **Хостинг и переезд:** nginx по `engine/tools/nginx.conf.example`,
   докрут `public/`, 301 со старых адресов, `sitemap.py`, `robots.txt`.
5. **Копия файла Figma под клиента** `konfeta v.0.X SEO DS` — когда
   пойдут правки с дизайнером.

## Локально

```
python3 engine/tools/build.py            сборка CSS и JS в public/assets
php engine/tools/render.php index.php > /tmp/konfeta.html
```

Сервер на машине не поднимается, поэтому страница смотрится слепком:
`render.php` подставляет докрут и отдаёт готовый HTML.
